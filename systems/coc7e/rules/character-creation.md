# CoC 7e 车卡规则（character creation）

> 本文件是「克苏鲁的呼唤 第七版」车卡阶段的**机制与参数**说明，供 agent（PL/master）照此
> 生成角色卡。**不含硬编码引擎**：掷骰必须调用确定性工具 `tools/dice.py`（带种子、可复现），
> agent 不得自造随机数；派生值与技能点由 agent 依本文件计算并写入卡面。
>
> 判定结算 `check resolve` 的完整实现推迟到扮演/战斗阶段；本文件只固化判定档位与
> **大成功 = 1–5** 等参数，供后续工具使用。

## 1. 属性（Characteristics）

调查员有 **8 项属性**，每项以骰子生成（工具输出即真相，须记录 seed）：

| 属性 | 含义 | 生成式 |
|---|---|---|
| STR | 力量 | `3d6×5` |
| CON | 体质 | `3d6×5` |
| SIZ | 体型 | `3d6×5` |
| DEX | 敏捷 | `3d6×5` |
| APP | 外貌 | `3d6×5` |
| INT | 智力 | `3d6×5` |
| POW | 意志 | `3d6×5` |
| EDU | 教育 | `(2d6+6)×5` |

> 说明：本实现采用**一条命令固定规则**——8 项属性中除 `EDU` 使用 `(2d6+6)×5` 外，
> 其余 7 项（`STR/CON/SIZ/DEX/APP/INT/POW`）均为 `3d6×5`。该口径由本规则文件固化，
> 便于批量掷骰与复核。

对应工具调用示例（建议一条命令掷一组，保留 seed）：

```bash
uv run tools/dice.py roll --expr 3d6 --count 7 --seed <seed>     # STR/CON/SIZ/DEX/APP/INT/POW
uv run tools/dice.py roll --expr "2d6+6" --seed <seed>           # EDU
uv run tools/dice.py roll --expr 3d6 --seed <seed>               # 幸运
```

每项属性 = 骰点合计 × 5。

## 2. 派生值（Derived）

| 派生值 | 公式 | 说明 |
|---|---|---|
| HP（体力） | `⌊(CON + SIZ) / 10⌋` | 向下取整 |
| MP（魔法点） | `⌊POW / 5⌋` | |
| SAN（理智） | `= POW` | 初始理智；后续只减不增（奖励例外） |
| 幸运（Luck） | `3d6×5` | 独立掷骰，与属性分开 |
| DB（伤害加值） | 见下表（由 `STR + SIZ` 决定） | |
| Build（体格） | 见下表（由 `STR + SIZ` 决定） | |
| MOV（移动力） | 见下 | 由 STR/DEX 与 SIZ 比较、并受年龄影响 |

### 2.1 DB / Build 表

| `STR + SIZ` | DB | Build |
|---|---|---|
| 2 – 64 | `-2` | −2 |
| 65 – 84 | `-1` | −1 |
| 85 – 124 | `0` | 0 |
| 125 – 164 | `+1d4` | +1 |
| 165 – 204 | `+1d6` | +2 |
| 205 – 284 | `+2d6` | +3 |
| 285 – 364 | `+3d6` | +4 |
| 365 – 444 | `+4d6` | +5 |
| 每再 +80 | 再 +`1d6` | 再 +1 |

### 2.2 MOV

基准 MOV 由 `STR`、`DEX` 与 `SIZ` 比较决定：

| 条件 | MOV |
|---|---|
| STR 与 DEX 都**小于** SIZ | 7 |
| STR 或 DEX **不小于** SIZ（其一 ≥ SIZ） | 8 |
| STR 与 DEX 都**大于** SIZ | 9 |

年龄修正：年龄每超过 39 岁满 10 年，MOV −1（40–49 岁 −1，50–59 岁 −2，依此类推）。

## 3. 年龄修正（可选）

> MVP 允许简化；若采用，须在卡面 `backstory`/`ageNote` 注明所用分档。

| 年龄 | 修正 |
|---|---|
| 15–19 | STR −5、SIZ −5、EDU −5；幸运掷两次取高 |
| 20–39 | 无属性修正；可做 1 次 EDU 成长检定 |
| 40–49 | STR/CON/DEX 合计 −5（自行分配）；APP −5；2 次 EDU 成长检定 |
| 50–59 | STR/CON/DEX 合计 −10；APP −10；3 次 EDU 成长检定 |
| 60–69 | STR/CON/DEX 合计 −20；APP −15；4 次 EDU 成长检定 |
| 70–79 | STR/CON/DEX 合计 −40；APP −20；4 次 EDU 成长检定 |
| 80–89 | STR/CON/DEX 合计 −80；APP −25；4 次 EDU 成长检定 |

「EDU 成长检定」：掷 `1d100`，> 当前 EDU 则 EDU +`1d10`（上限 99）。工具执行、结果落盘。

## 4. 职业与技能（Occupation & Skills）

### 4.1 流程

1. 选择**职业**；从该职业的职业技能表中确定 **8 项本职技能**（职业不足 8 项时可自选补足）。
2. **职业技能点** = `EDU × 4`，只可分配到本职技能（含信用评级）。
3. **兴趣技能点** = `INT × 2`，可分配到任意非本职技能。
4. 每项技能最终值 = **基础值 + 分配点数**；点数不可使技能超过 99。
5. 信用评级（Credit Rating）占用职业技能点，取值范围由职业决定。

## 5. 判定参数（供后续 `check resolve` 使用）

本阶段只**文档化**参数，不实现结算工具；后续阶段依此实现。

| 档位 | 条件（目标值为 T，骰点 d100 为 r） |
|---|---|
| **大成功（Critical）** | `r ∈ 1–5` |
| 极难成功（Extreme） | `r ≤ ⌊T/5⌋` |
| 困难成功（Hard） | `r ≤ ⌊T/2⌋` |
| 常规成功（Regular） | `r ≤ T` |
| 失败（Failure） | `r > T` |
| **大失败（Fumble）** | `T < 50` 时 `r ∈ 96–100`；`T ≥ 50` 时 `r = 100` |

- **大成功 = 骰值 1–5**（本实现的规则参数，可在 system 配置中调整）。
- 奖励骰/惩罚骰（bonus/penalty die）与对抗判定留待后续阶段实现。
- 幸运可作为「花费幸运改判」资源（可选规则，后续实现）。

## 6. 卡面产出（`roles/<id>/sheet.md` + `sheet.json`）

车卡结束须同时写出**人读**与**机读**两份卡面：

### 6.1 `roles/<id>/sheet.md`（人读）

包含：角色名 / 玩家 / 职业 / 年龄 / 性别；属性表；派生值表；技能表（标注本职与分配点数）；
背景故事；随身物品（车卡阶段通常为空/白袍）。

### 6.2 `roles/<id>/sheet.json`（机读）

固定结构（字段名如下，供 `context build` 与后续工具读取）：

```json
{
  "system": "coc7e",
  "name": "角色名",
  "player": "pl1",
  "occupation": "医生",
  "age": 30,
  "gender": "女",
  "attributes": { "STR": 50, "CON": 60, "SIZ": 55, "DEX": 65, "APP": 55, "INT": 65, "POW": 60, "EDU": 75 },
  "derived": { "HP": 11, "MP": 12, "SAN": 60, "Luck": 55, "DB": "0", "Build": 0, "MOV": 8 },
  "skillPoints": { "occupation": 300, "interest": 140 },
  "occupationSkills": ["急救", "医学", "外语(拉丁语)", "心理学", "科学(生物学)", "精神分析", "说服", "信用评级"],
  "skills": { "急救": 60, "医学": 55, "图书馆使用": 60, "侦查": 55, "聆听": 45, "母语": 75, "闪避": 32 },
  "backstory": "……",
  "inventory": ["破旧的白袍"],
  "rolls": { "seed": 12345, "attributes": "3d6×5 / 2d6+6", "luck": "3d6×5" }
}
```

- `skills`：至少含 8 项本职技能；值 = 基础 + 分配。
- `derived.DB` 用字符串（如 `"-1"`、`"0"`、`"+1d6"`）。
- `rolls.seed` 记录本卡所用工具 seed，保证可复现。
